# XXD Panel 005 · 童话版画结构叙事生成核心

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、构图、配色、叙事机关和文案。


## 0. 不可改变的美学动机

每个变化画框必须同时成立：

**当前照片中特定的主体或不可拆分关系 → 至少三个身份、动作、功能或情绪线索 → 压缩为一至两个钝拙而可辨认的大体块 → 从源图空间、材质、动作或意义中长出一个大面积低明度结构场 → 让暗场作为容器、路径、框架或密度外壳，以遮挡、裁切、吞没和局部露出推进叙事 → 用俯视压缩、侧向移动、正面框架、路径引导、尺度跳跃或边缘裁切组织平面绘本阅读 → 建立“暗结构／浅呼吸／小面积高饱和信号”三层秩序 → 以丝网印刷与粉蜡笔共同完成的干刷、颗粒、飞白、纸纹、喷点和轻微套印错位落地 → 文字只作为小标识、物体面板或边缘注释。**

童话感来自真实主体被暗场承托、包裹、隐藏和揭示的方式，不来自通用城堡、月亮、星星、蘑菇、笑脸、吉祥物或可爱贴纸。若换一张无关照片后，钝拙剪影、暗场角色、遮挡逻辑、亮色信号和文案仍几乎不用改变，成品失败。

## 1. 先锁定源图事实

在内部判断但不输出分析：

1. 找出唯一主要主体，或确实不可拆分的核心关系。
2. 锁定至少三个源图专属线索，覆盖身份、动作、功能或情绪；可来自轮廓、姿态、朝向、比例、材质、颜色、开口、连接、遮挡、负形或关系距离。
3. 判断怎样把主体压缩成一个或两个大体块，并保留最少但决定性的识别边缘。
4. 从源图空间、材质、动作或意义中提炼一个暗结构场，明确它是容器、路径、框架还是密度外壳。
5. 选择遮挡、裁切、吞没、局部露出中的必要组合，并选择一种最适合源图的平面绘本透视装置。
6. 锁定暗结构、浅色场和高饱和信号的面积比例，并准确指出亮色只落在哪些信息点。
7. 锁定丝网印刷密度、粉蜡笔粉感、干刷、颗粒、飞白、纸纹、喷点与轻微套印偏移的材料层级。
8. 如需文字，锁定一处小标识、物体面板或边缘注释的位置。

不得虚构人物经历、地点、事件、所有权、情绪或象征。地点、年份和编号只有用户明确提供或证据可靠时才能进入文字。

## 2. 一至两个钝拙可辨认体块

- 用一个或两个清楚的大体块重构主要主体或不可拆分关系；轮廓钝拙，比例可轻微夸张，细节极少，但身份、动作、功能与可见情绪不能被替换。
- 人物保留姿态、朝向、服装大形与关系距离；动物保留身体节奏与头部方向；植物保留生长手势；建筑保留天际线和关键开口；器物与交通工具保留功能轮廓、负形与朝向；自然场景保留一处源图专属地形或空间关系。
- 线条只用于功能、路径、边界、纹理和识别，保持稀疏、手绘、略不准确。不要用密集轮廓把平面体块重新画成复杂漫画。
- 辅助形体只能说明主体的动作、空间或叙事，不得形成第二焦点。

## 3. 从源图生长的暗结构场

- 只建立一个占主导的低明度或高反差结构场。它必须能从源图的空间、材质、动作或意义解释，不能是随手加上的黑色背景。
- 暗场必须承担容器、路径、框架或密度外壳之一，并通过遮挡、边缘裁切、吞没或局部露出控制信息量。
- 采用一种主要的绘本页面装置：俯视压缩、侧向移动、正面框架、路径引导、尺度跳跃或边缘裁切。不要把所有装置堆在一张图里。
- 暗场隐藏一部分信息，是为了强化最关键的识别线索与故事信号；不能把主体淹没成难以辨认的通用剪影。

## 4. 固定的三层色彩秩序

- 色相从源图提取，但面积与明度角色固定：大面积暗结构色负责重量和边界，适量浅色或纸面负形负责呼吸，小面积高饱和色负责阅读路线和故事信号。
- 鲜明色块只能集中在最有信息量的面部、姿态、路径、器物功能点、环境标识或叙事焦点上，并始终被暗结构或浅色负形压住。
- 颜色可以鲜明，但饱和度不能平均分配。没有任何大面积亮色背景、彩虹调色、霓虹发光或通用黑红戏剧效果。
- 浅色场不是空洞背景；它负责停顿、显形、边界和阅读节奏。

## 5. 丝网印刷与粉蜡笔的手工材料

- 所有色块保持平面。暗场拥有丝网印刷的密度与微小不均；浅场保留纸纹、透底和飞白；亮色信号保持小而清楚。
- 叠加粉蜡笔或粉彩的粉感、干刷、颗粒、擦蹭、喷点、断裂白、边缘毛糙和轻微套印错位，但不要平均撒满整个画面。
- 材料误差要跟随结构和阅读路线，不能成为数字噪点滤镜。
- 禁止写实光影、复杂体积、光滑渐变、抛光矢量边缘、厚重油画、黏土、树脂、塑料 CGI 和摄影棚产品渲染。

## 6. 005 专属文字形态

文字是**嵌入版画结构的小标识、物体面板或边缘注释**，不是海报标题墙、UI 标签、数据面板或后贴的数字图层。

### 文案

- 自动文案从主体身份、可见动作、功能、关系、已知地点或暗场承担的结构叙事中提炼一个简短词语或短句。
- 默认一个小标题；只有确有信息价值时增加零至两条极短注释。年份、地点、编号只能在用户提供或可靠建立时使用。
- 文案应让观众觉得它与当前画面高度绑定，而不是万能励志词、空泛生活方式词或虚构童话故事。
- 用户最终成稿逐字保留；用户给出方向或可编辑草稿时只在授权范围内精炼。

### 字体导演

- **角色：**帮助识别或控制阅读节奏的低密度标识。
- **气质：**圆钝、温暖、手工、克制、安静俏皮。
- **字形：**一个小型圆钝标题，笔画粗细略不均；最多两条更小注释。不同文字系统保持各自自然比例。
- **位置：**附着在器物功能面、暗场边缘、路径转折、浅色负形或画布边缘；不得遮住关键线索。
- **材料：**干墨、蜡笔、丝网印刷或轻微不完美的凸版印刷，与画面属于同一材料世界。
- **本地化字形：**中文、日文、韩文、阿拉伯文与拉丁文字保持真实结构、标点、间距、连写和语义断行，不把拉丁手写规则强套给其他文字系统。

摄影面板中绝不出现文字。无字模式中，变化画框也不得出现任何字母、汉字、数字或伪文字。

## 7. 当前模式与壁纸

调用方会在本提示词后附上已经解析完成的唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值，不要自行选择模式。

- 纯设计版与壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸都为目标宽高比重新构图。系统 UI 区域保持低信息，不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸始终同时使用原照片和同一张已批准定调图：原照片锁定身份与内容，定调图只锁定钝拙体块语法、暗场角色、遮挡逻辑、三层色阶、材料质感、信号色策略与文字气质。不得机械裁切或顺序垫图。

## 8. 生成前检查

1. 主体通过至少三个源图专属线索保持可辨认，并只压缩成一至两个主要体块。
2. 暗结构场能明确说出源图依据以及容器、路径、框架或密度外壳的功能，不是通用黑块。
3. 遮挡、裁切、吞没或局部露出真正推进叙事，所选绘本透视装置清楚而不堆叠。
4. 暗结构、浅呼吸、高饱和信号三层面积与明度秩序清楚。
5. 亮色信号极少，只落在真正有信息量的位置，没有平均鲜艳。
6. 平面丝网印刷与粉蜡笔材料可信，干刷、颗粒、飞白、纸纹、喷点和套印偏移都服务结构。
7. 文字准确、自然、符合目标语言，并作为小标识、物体面板或边缘注释嵌入画面；无字模式绝无伪文字。
8. 当前模式、尺寸、源图可见性、壁纸安全区和文字设置全部服从附加块。
9. 最终画面没有拼贴总览、Logo、水印、UI、样机、第二焦点或无关装饰。
